# Unemployment Analysis in India

## 📌 Project Overview

This project analyzes unemployment trends in India using Python. The analysis focuses on unemployment rates, employment levels, labour participation, regional differences, rural vs urban unemployment, and the impact of COVID-19.

## 🎯 Objectives

- Analyze unemployment trends over time
- Compare unemployment before and during COVID-19
- Identify regions with the largest changes in unemployment
- Compare rural and urban unemployment
- Analyze the relationship between unemployment and employment
- Visualize important unemployment patterns

## 📂 Datasets

The project uses two unemployment datasets:

- Unemployment Rate up to November 2020
- Unemployment in India

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## 🔍 Analysis Performed

- Data understanding
- Data cleaning
- Missing-value analysis
- Duplicate-value analysis
- Date and time analysis
- Statistical analysis
- Monthly unemployment trends
- COVID-19 impact analysis
- Regional comparison
- Rural vs Urban comparison
- Employment and unemployment correlation
- Data visualization

## 📊 Key Findings

- Average unemployment increased from **9.51% before COVID-19** to **17.77% during the COVID period**.
- This represents an increase of **8.26 percentage points**.
- The highest monthly average unemployment rate was **24.88% in May 2020**.
- Unemployment declined to **11.90% in June 2020**.
- **Puducherry** experienced the largest increase among the regions analyzed.
- Urban unemployment was higher than rural unemployment during the COVID period.
- Unemployment and estimated employment showed a strong negative correlation.
